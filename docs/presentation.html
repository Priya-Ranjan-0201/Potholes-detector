◆ 04. DEFECT TAXONOMY 05 / 12

Distress Taxonomy & ASTM D6433 Severity Scoring

Four canonical civil damage classes mapped to engineering repair specifications.

Class 0: POTHOLE

Bowl-shaped cavity with sharp vertical edges. Direct hazard to vehicle tires, suspensions, and two-wheeler balance.

★ IRC: Bitumen mastic compaction within 24h
Class 1: CRACK_LONG

Longitudinal crack parallel to road centerline. Caused by pavement fatigue, poor paving seams, or heavy wheel loads.

★ IRC: Hot-pour rubberized bitumen seal
Class 2: CRACK_TRANS

Transverse fracture running perpendicular to traffic flow. Driven by thermal shrinkage and subgrade settlement.

★ IRC: Routing and crack elastomeric sealing
Class 3: CRACK_ALLIGATOR

Interconnected webbed fatigue cracking resembling reptile skin. Indicates structural subbase failure and water penetration.

★ IRC: Full-depth asphalt mill & replace
Mathematical Severity Model: Score = BaseWeight × AreaRatio + WheelPathPenalty(+15) + DepthIndex(+20) + ClusterDensity(+10)

◆ 07. MODEL RESCUE FORENSICS 08 / 12

The Engineering Breakthrough: Eliminating Hallucinations

How forensic root-cause analysis solved the 'identifying anything' bug.

THE GLITCH: 'IDENTIFYING ANYTHING'
Uncalibrated Border Boxes & Noise
  • • Border Ghost Boxes: Corrupt edge weights generated phantom boxes on left (x < 16%) and right (x > 87%) margins of every image.
  • • Texture Clutter Hallucinations: Faint asphalt gravel variations and shadow borders triggered false positive detections.
  • • Non-Road Misclassifications: Sky, trees, and signboards were falsely flagged as alligator cracking.
  • • Overly Sensitive Thresholds: Default 0.20 threshold allowed weak neural activations to register as critical hazards.
THE CURE: 1,100 REAL-WORLD IMAGES
Defensive Re-Training & Calibration
  • • Curated Real-World Dataset: Assembled 1,100 authentic images (935 train + 165 val) from RDD2022 India and GitHub Potholes.
  • • 150 Hard Negative Regularizers: Trained on clean non-damaged asphalt to teach zero activations on clean pavement.
  • • Perimeter Exclusion Filter: Programmatically rejected boxes hugging boundaries (x < 3% or x > 97%) with conf < 0.45.
  • • Calibrated Presets: Raised balanced threshold to 0.30 for potholes and 0.32 for cracks.
★ Verified Outcome: 0 border phantom boxes across all test images · 0.0% false alarms on clean roads · 92.28% validation precision.

ACADEMIC INSIGHT: WHY CRACKS ARE HARD

Computer Vision Physics

  • • Class Imbalance: Training data had 1,586 potholes but only 98 alligator cracks. Gradients heavily biased toward concave hole depressions.
  • • Downsampling Loss: A 1080p image letterboxed to 640x640 shrinks a 2-pixel crack to sub-pixel width (<0.7 px), making it invisible against tarmac texture.
  • • The Solution: Slicing Aided Hyper Inference (SAHI) tiles the road into full-res 640x640 crops with zero downsampling blur.
★ Conclusion: ScamRoad is a reliable, high-precision POTHOLE detector; cracks require high-resolution patch tiling.
